# Lavalink v4 migration

This branch is the isolated migration track for replacing the legacy Erela.js/Lavalink integration with a Lavalink v4-compatible client stack.

Target stack:

- Discord.js 13 (temporarily retained to keep this migration incremental)
- Kazagumo
- Shoukaku
- Lavalink 4.x

The existing v6 branch remains the Render baseline until the migration is verified.
